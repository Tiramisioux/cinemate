Playback settings

Use conform frame rate —
Plays every take on the project's conform rate, from settings.conform_frame_rate. A take shot faster than the conform rate plays as slow motion — the same speed it will run on the timeline. Off plays each take at the rate it was shot.
Preview scale
Decode cost and card read bandwidth both fall with scale. A half is the finest a Bayer cell allows without interpolating.
Monochrome sensor
cinepi-raw tags every frame with a colour filter array even on a mono sensor, so nothing on the card distinguishes them. Set it per take.
